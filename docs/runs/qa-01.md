# Independent P0 verification

The Circulation build passed deterministic host integration. The live-browser and listening gates remain open.

## Reproduction

Run these commands from the source root.

```sh
npm run build
npm run check:contract
npm test
node tests/host-integration.mjs
python tests/browser_smoke.py --soak-minutes 10
```

The final command requires Python Playwright and working Chromium. Use `--chromium /path/to/chromium` to select an executable or `--screenshots /path/to/output` to retain browser captures.

## Observed results

- The built HTML tested in the host integration run had SHA-256 `238d308d044b2494d0ec9147524c0cb28ddcdeb62ec14fb93cac879f87ef46d8`. The static HTTP server returned the same artifact bytes with status 200 and content type `text/html` to a Python client. Production source and build inspection found inline styles and scripts, a data favicon, and no fixture imports, remote assets, or network request paths.
- The host test executes the release’s inline script against a deterministic clock and stand-ins for the DOM, Canvas and Web Audio APIs. Idle starts empty, the first impulse yielded eight captures and eight note schedules, and the guided run gave R0 captures at 0, 240, 720 and 1200 ms with the R1 block at 300 ms. Production Guide enqueues two stimuli. The engine provides every downstream wave.
- Pause held the committed state and resumed the existing generation. Simulated audio suspension and page visibility loss both required explicit resume. A Guide request while audio was suspended queued the new run and waited for resume. Cutting L4 and L1 ended the rhythm, and restoring those connections left the circuit quiet.
- The host test advanced the clock by 20 synthetic minutes at 4×, equivalent to 300 seconds of model time. The last sample contained 5,005 captures, 4,096 retained UI events, 10,923 pruned UI events, 4,096 retained engine batches, one queued engine item, and one scheduler timer. The mixer reported 4 live sources, a peak of 8 sources, 13 cached buffers, and zero duplicate schedules. Fourteen subsequent Reset presses cleared prior run events and the final reset left zero live mixer sources. No bundle errors were trapped by the host test.
- The host clock and API stand-ins exercise state wiring and retention. Browser memory, CPU/GPU use, audible timing, and frame rate remain unmeasured.
