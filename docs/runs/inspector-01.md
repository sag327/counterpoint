The Laboratory reads the transport's presented snapshot, retained events up to that simulation tick, and mixer diagnostics. It shows committed engine time separately so a capture scheduled ahead of presentation does not appear early in the log, site state, or raster. Current automatic cycles start with the world configuration and incorporate presented cycle-parameter changes. The last same-site activation interval is the measured cycle length shown in the site readout and raster. For blocked attempts, the log shows time since the preceding same-site capture when that capture is retained.

The 2,400 ms raster uses separate shapes for captures, blocks, and external stimuli. The event log shows the latest 80 matching events from the app's retained history, with independent accepted, blocked, propagating, and other-event filters. The log exposes individual times for screen-reader users. Site and link selectors, stimulation, and cut or restore actions route through the app's ordinary command handlers.

The Circulation S1/S2 control resets the run and applies both stimuli to R0 with a user-entered coupling interval from 1 to 5,000 simulated ms in whole milliseconds. Invalid entries stay out of the application callback. The Conduction protocol resets and applies the reference impulse at A at 275 simulated ms. Reset and one-impulse controls name their reset effect. Pacing trains remain optional future work. Audio values use mixer diagnostics when sound has started.
