The scheduler wakes every 25 wall ms and floors its 60 wall-ms lookahead to the latest eligible engine tick. Live input uses the later of one tick past the commit horizon and the rounded-up 5 wall-ms margin. In a timely foreground wake, input onset targets are at most 60 wall ms plus one engine tick (0.004 wall ms at 4×). Manual pause leaves the committed boundary in place. A wake or frame acknowledges the pause when the clock reaches the boundary. Visibility loss, audio suspension, and missed lookahead use the immediate interruption path and record `lastInterruption` from the last rendered frame through the committed horizon.

`reset(world, runId, {commands, start})` clears the run and queues guide commands before the first `advanceTo`. `resume()` anchors the current clock at the frozen model position. `submit(fields)` returns the accepted timestamped command. `commandLog()` retains the most recent 4096 accepted commands for the current run and `discardedCommandCount` counts earlier entries. `onCommit(events)` receives completed batches before presentation and can map an event through `audioSecAt(event.tMs)`. `frame()` returns the presentation cursor, the engine snapshot at that cursor, and newly visible events. `onSilence({runId, reason})` fences the old mixer schedule. `onFault(error)` exposes complete batches and the failed instant for diagnostics.
