# Unknown (Coda)

## The musical idea

A rhythm with no label. You hear it and pick it apart, as one does with any puzzle.

## What the tissue is doing

A hidden arrangement of tissue produces the rhythm. Which one is for you to work out, using only what you can pace and hear.

## How the model makes it

In this lumped-element model, each puzzle is generated from the same engine as the other studies. Nothing in it is scripted, and no clinical conclusion should be drawn.

## A note from history

Josephson's textbook is the standard general reference for the maneuvers used to work out an unknown rhythm.

## Try this

Tap and listen, then say what you think is hidden.
